# 游戏内邮件

入口位于任务左侧。每份存档的收件码显示在邮箱顶部；群发不需要收件码。邮件可离线阅读缓存，联网刷新后接收新邮件；阅读与领取分开，附件事务化发放，存档成功后展示奖励。重复领取、过期、无效附件与发放失败不领取。

管理员：在仓库运行以下命令，一次生成并发布一封群发邮件（不会把管理员凭证打进游戏）。

```powershell
.\.venv\Scripts\python.exe tools/send_game_mail.py --title "邮件标题" --body "邮件正文" --reward 700001=1000 --reward 220001=1 --to all --publish
```

指定玩家：将 all 改成玩家邮箱内的32位收件码，多个码用逗号分隔。--expires-at 可指定带时区的截止时间，例如 2026-12-01T00:00:00+08:00。省略 --publish 仅写入本地 distribution/mailbox.json，不会发出；之后用 git 提交该文件并推送即可，无需重新生成同一封邮件。每封邮件ID不可复用；修改内容应发送新的ID。游戏从 GitHub raw/CDN读取公开的 distribution/mailbox.json，不上传存档和收件码；这是单机存档中的领取记录，不是服务器账号系统。

邮件附件可以使用原表 Money、Item、Pet 编号，宠物单封最多6只。初始正式邮件为空，不向用户发送测试奖励。通知列表缓存上限500封，领取凭证继续保留。邮件需要联网刷新一次，已有缓存离线仍可查看和领取。
