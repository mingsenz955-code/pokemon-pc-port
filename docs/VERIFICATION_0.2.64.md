# 0.2.64 验证记录

## 本版行为

- F11 或 Alt+Enter 切换全屏，Esc 退回窗口。窗口可调整大小，画面等比缩放；地图、战斗、任务及主窗口内弹窗的输入坐标同步换算，宽高比不合时留边。没有更改逻辑分辨率或地图行走速度。
- 背景音乐随原地图 bgmId、NPC 战斗 bgmId、野外战斗切换，返回地图恢复场景音乐。原 Sound.name2 将 34 个 BGM 编号映射至包内 10 个实际 MP3，全部可解析、可经 Windows MCI 解码。没有音乐欣赏页或音乐商品。
- ARM 原 BattleFightSuccessEvent / BattleFightFailedEvent / BattleController::catchPetRespond 调用 SoundPlayer::playBgMusic：胜利 401、失败 402、捕获 403，均为非循环；普通地图及战斗音乐循环。音频开播操作在独立线程，不阻塞 Tk 刷新；同曲不因每帧调用重启。系统音乐/音效开关有效，状态随正常存档保存；原剧情数字 sound 和技能音效使用同一音效开关。
- 取消充值入口，不接支付 SDK。原 Store 人民币 costCount 的单位为分，按每分 100 金币转换，即 1 元 10000 金币；只改内存表，不重写原资源文件。徽章、荣誉、奖牌等游戏货币保留。纯金币充值商品下架，业务层也拒绝金币购买金币。
- 原付费道具/礼包使用金币确认购买、原表发奖、限购、原奖励弹窗；宠物使者可以购买永久宠物，已有同一试用宠物原位转永久。原 5 元材料豁免进化改为 50000 金币，仍检查进化等级；原材料进化继续保留。旧存档人民币余额仅在读取时一次性兑换为金币，不改正在运行的玩家存档。
- 日常领取奖励先刷新完整地图底图，奖励层不继承任务/确认框模板。单张奖励居中，标题和名称在纸张内，确认后回到已领取的日常页，不重复发奖。金币价格位图文字有显式尺寸约束，六位数不溢出购买按钮。
