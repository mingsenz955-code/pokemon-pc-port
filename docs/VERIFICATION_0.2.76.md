# 0.2.76 老人传送后左出口卡死

基于 main/2ce561a（0.2.75），保留孵化教学、抽宠、骑乘、轮盘/宝箱及离线引导修复。

## 已复现的原因

原路线 pEvent109004 把玩家送到向阳平原 11402，随后 pEvent114001 结束老人告别。往左穿过 11401 到达向阳村 11503 时，地图 115 的 NPC 11509 配置 face=""，actor_animation 调用 int("") 抛出 ValueError。异常发生在 Tk 绘制回调里，下次 tick 尚未排入队列，导致画面停住。并非单纯刷新率不足。

另一个同路线问题是 request_map 先把主线 14 的“到达向阳村”状态改为 4，再通知入图剧情；pEvent115001 要求任务状态 3，因此被错误挡住。

## 修复与兼容

- 空朝向与缺少朝向统一采用原有向下默认姿态，保留有效数字和剧情设置的朝向。扫描全部原地图，空朝向共三处，分别在地图 115、305、7801；三图均实际绘制验证。
- 地图进入时先通知原剧情触发，再更新到达地图的任务计数，不提前绕过入场剧情。
- 读取旧存档时，仅在地图 115、主线 14 状态 4、原前置事件 5901002 完成、115001 尚未完成且没有运行中剧情/移动时，启动漏掉的原入场脚本。保留任务计数，由原剧情提交任务和发奖励；不直接伪造完成，也不覆盖其他运行中剧情。

## 验证

新增 tools/check_teleport_exit.py 三项隔离回归：

1. 从比奇城原触发开始，实际执行老人对话与移动、传送、平原告别，再用真实点击寻路走过左侧出口。实际绘制向阳村、执行两名 NPC 的入场剧情、提交主线 14 并进入任务 15；运行 Tk 主循环，确认继续有多次画面上传且没有回调异常，人物可继续移动。
2. 扫描所有原地图，找出空 face 的三张地图，校验人物默认姿态并实际绘制。
3. 保存并读取旧版漏掉向阳村剧情的任务 14 就绪状态，补执行原剧情；再次存读档，验证任务与奖励都只完成一次。

修复前新增路线和空字段检查均以相同 ValueError 失败；修复后通过。另运行任务计数、剧情镜头、剧情移动、点击寻路、孵化教学回归。镜头检查的轻量宿主补齐 ui_info 与 audio 回调，未改变游戏逻辑来适配夹具。日志位于本机 outputs/verification/teleport-exit。

Windows 发布包用临时存档执行启动检查。没有修改玩家真实存档，没有强制关闭现有游戏。此版本修复上述确定性问题，不代表所有地图和后期剧情都已连续试玩通关。
