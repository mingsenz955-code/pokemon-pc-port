- 出场：直接核对 X 核心 `PetController::executeAction`（0x2d2cf8）、完成回调（0x2d2980）及数组 0x7cf078，玩家依次播放 `Animation6/2/1/3/5`，对手使用 `Animation8/2/1/3/5_0.8`。不再固定播放错误的 Animation4。根据 Animation3 的 `out` 事件出宠，恢复 0.6 秒上升缩放淡出、0.7 秒回弹及透明度变化，最后移除球。野生对手提前在场，不套玩家出球缩放。
